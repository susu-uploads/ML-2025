1. Продемонстрировать на примере любой из задач, которую вы решали в течение семестра, расчет метрик оценки модели (вывести число или построить график в зависимости от метрики):

- MSE;

- MAE;

- RMSE;

- Accuracy;

- Recall;

- Precision;

- AUC-ROC;

- F1;

- F2;

- Mathews;

- С-index;

- одна любая другая метрика.

2. Написать краткий комментарий, для чего нужны все эти метрики, область их применения.

В качестве ответа загрузить блокнот с запущенным кодом и комментариями.

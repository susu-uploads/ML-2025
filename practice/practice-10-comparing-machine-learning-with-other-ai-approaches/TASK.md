1. Выбрать простую задачу классификации или прогнозирования (например, прогноз температуры воздуха). Датасет можно составить искусственный, самостоятельно.

2. Реализовать решение задачи любым методом машинного обучения.

3. Реализовать решение задачи любым одним из последующих методов:

- байесовским методом;

- алгоритмами нечеткой логики;

- эволюционным алгоритмом;

- на любом функциональном языке программирования;

- на любом языке логического программирования.

4. Написать вывод о результатах решения задачи двумя разными методами: точность, сложность понимания, вычислительная сложность, объем занимаемой памяти и т.д.
